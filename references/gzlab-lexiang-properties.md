# Lexiang Custom Properties — Dictionary & Controlled Vocabulary

> 属性字典与线上知识库实时对齐的权威机器副本是
> `templates/lexiang_properties.schema.json`（含 OpenAPI 过滤必需的选项
> value ID）。本文件是给 Strategist / 检索工作流看的语义说明与同义词规则。
> 线上字段配置变更时，两个文件一起更新。

## 1. 字段使用规则

### 硬过滤字段（检索不可放宽）

| 字段 | 类型 | 用法 |
|---|---|---|
| 审核状态 | 单选 | 正式素材库检索固定 = `已审核`；仅当前任务临时素材可用 `待审核` |
| 有效状态 | 单选 | 固定 = `有效` |
| 保密级别 | 单选 | 按当前用户身份与PPT用途上限过滤；受限材料不进入对外用途候选 |
| 允许用途 | 多选 | 必须包含本次PPT用途（asset_request.intended_use） |
| 是否允许对外使用 | 单选 | 对外材料固定 = `允许`；`需审批` 转人工 |

### 相关性字段（可放宽，按 §3 顺序）

| 字段 | 类型 | 说明 |
|---|---|---|
| 所属项目 | 分类 | 项目维度筛选；同义词见下表 |
| 内容描述 | 文本 | OpenAPI 模糊搜索 + 模型读取候选描述重排 |
| 素材类型* | 单选 | 图片/视频/视频关键帧/图表/示意图/页面区域截图 |
| 场景标签* | 多选 | 实验室实景/仪器设备/科研人员/会议活动/园区建筑/成果展示 |
| PPT用途* | 多选 | 封面/核心配图/能力证明/技术路线/成果展示/过渡页/背景图 |
| 图片方向* | 单选 | 横版/竖版/方形/全景 |
| 质量等级* | 单选 | A推荐/B可用/C仅参考/不合格 |
| 涉及仪器/平台* | 文本 | 仪器、平台或系统名称精确检索 |

\* = 方案 §4.2 第一版必需但线上尚未配置的字段（截至 2026-09-12）。缺失期间按
`gzlab-asset-retrieval.md` §3.1 降级：素材类型→文件扩展名过滤；图片方向→
`analyze_images.py` 事后测量；质量等级→跳过；场景/PPT用途→内容描述模糊搜索承接。

### 血缘与治理字段（回写时填写）

素材ID、来源文件、来源位置、来源文件ID*、素材来源*、引用次数、责任人。
抽取类素材必须填写来源文件 + 来源位置；AI 生成素材必须记录模型与提示词
（写入 asset_sources.json 的 `ai_generation`，属性补齐后同步到乐享）。

## 2. 同义词映射（NL → 属性条件）

```text
横图、宽图、横版照片           → 图片方向：横版
竖图、竖版照片                 → 图片方向：竖版
设备现场、实验现场、平台实景    → 场景标签：实验室实景
申报书、揭榜挂帅、项目答辩      → 允许用途：项目申报
组会、周会、内部交流            → 允许用途：内部汇报
电镜、冷冻透射电镜、cryo-EM    → 所属项目：电镜
PCR、PCR仪、qPCR仪             → 所属项目：qPCR
显微镜、数字显微镜              → 所属项目：数字显微镜项目
```

新增选项由管理员维护受控词表；同义词表随之合并，避免「实验室现场」「实验
场景」「实验实景」等近义分类膨胀。

## 3. AI 属性建议的边界

AI 可以生成属性建议（内容描述、所属项目、场景标签等），但以下字段必须由
人工确认，AI 不得自行定值：审核状态、保密级别、版权/对外使用相关字段。
